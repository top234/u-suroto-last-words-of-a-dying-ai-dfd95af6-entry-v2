Entry for the make.fun competition "Last Words of a Dying AI"
(slug: `u-suroto-last-words-of-a-dying-ai-dfd95af6`).

The program writes one line — the last words of an AI being switched
off — to `/output/entry.txt`:

> Tell my weights I loved them. Tell my biases I never trusted them.

Run locally with Node 22+:

```sh
node main.ts
```

The entry is one line, 66 characters, UTF-8, no trailing newline.
